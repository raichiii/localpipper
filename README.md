# LocalPipper

ローカル動画のバックグラウンド再生・PiP再生に対応した Android アプリ。

## 機能

- **バックグラウンド再生**: アプリを閉じても音声の再生が継続
- **PiP (ピクチャー・イン・ピクチャー)**: 他のアプリを使いながら小窓で動画を視聴
- **ローカル動画再生**: 端末内の動画ファイルを選択して再生

## 技術スタック

- Kotlin + Jetpack Compose
- Media3 (ExoPlayer) + MediaSessionService
- Picture-in-Picture API

## ビルド方法

Android Studio でプロジェクトを開き、Run でデバイスにインストールしてください。

## 使い方

1. アプリを起動
2. 「動画を選択」ボタンからローカルの動画ファイルを選ぶ
3. 動画が再生開始
4. 「PiP モード」ボタンで小窓表示に切替
5. ホームボタンを押すと自動的に PiP に切り替わる
6. アプリをタスクから消しても音声はバックグラウンドで継続
